# Contributing

Contributions are welcome through issues and pull requests on the official
upstream repository:

https://github.com/Elandrya2711/codex-podcast-studio

By submitting a pull request, patch, issue attachment, or other contribution,
you agree that your contribution is provided under the Codex Podcast Studio
Non-Commercial Upstream License 1.0.

## Rules for Contributions

- Do not include API keys, access tokens, private config files, generated
  podcast runs, voice samples, model weights, or proprietary third-party data.
- Keep changes focused and include tests when behavior changes.
- Improvements, forks, adaptations, and deployed modified versions must be
  returned to the official upstream project as a pull request or patch.
- Commercial use or commercial redistribution requires prior written permission
  from Elandrya2711.
